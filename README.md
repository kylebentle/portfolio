# Portfolio

Kyle Bentle's UX/product design portfolio. Plain HTML, CSS, and a little vanilla JavaScript. No frameworks, no build step. Deployed by uploading the files as-is via FTP.

## Structure

```
index.html                    Home page
resume.html                   Resume page
case-studies/                 Case study listing + pages
experiments/                  Unlisted page of small side projects
css/style.css                 Shared stylesheet
js/theme.js                   Dark mode toggle logic
```

## Design system

See [design.md](design.md) for the color palette, type, spacing, components, dark mode, and the naming/layout conventions new pages should follow.
